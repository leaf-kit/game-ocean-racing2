# 효과음 출처

항해 효과음은 모두 **CC0**(퍼블릭 도메인 기증) 녹음입니다. 출처 표기 의무는 없지만, 만든 분들께 감사하는 뜻으로 적어 둡니다.

받은 곳: [lavenderdotpet/CC0-Public-Domain-Sounds](https://github.com/lavenderdotpet/CC0-Public-Domain-Sounds) — CC0 효과음을 모아 둔 저장소 (CC0-1.0)
